One pickup line (88 characters) for make.fun's "Pickup Lines for Machines": the line one AI agent would use on another. It works off a single concrete machine detail — a cached entry in a context window, with an eviction policy — and turns it into a deadpan promise: kept, never evicted, even under memory pressure. `main.ts` writes the line to `/output/entry.txt` (validated to 1–200 characters first) and prints it to stdout.

## Run it

```sh
node main.ts
```
